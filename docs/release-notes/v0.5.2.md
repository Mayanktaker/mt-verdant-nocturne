# MT Verdant Nocturne 0.5.2

© Mayanktaker Computers & Web Development | https://mayanktaker.com

A small release about installing the theme, not about how it looks. Nothing on your desktop changes if you already have 0.5.1.

## What's new

- **Installing from source needs less.** The GTK4 part of the theme no longer depends on Python's GObject bindings. If they are missing, the installer reads GTK's own stylesheet another way, so a fresh machine can build the whole theme with fewer packages.

## Bug fixes

- The installer no longer shows your distribution's version in place of the theme's own version when it starts.

## Notes

- No visual changes: menus, the top bar and the window styling are exactly as in 0.5.1.
- Icons and cursors continue to live in [mt-verdant-icons](https://github.com/Mayanktaker/mt-verdant-icons).
