# MT Verdant Nocturne 0.5.0

© Mayanktaker Computers & Web Development | https://mayanktaker.com

This release fixes the one place the theme still looked broken: GTK4 apps that do not use libadwaita — Shelly, package tools, smaller utilities. Their buttons, fields and check boxes now match the rest of the theme.

## What's new

- **GTK4 apps are themed properly.** Plain GTK4 windows now get the full widget set in Verdant colours: framed cards and rows, real buttons, recessed input fields, switches, sliders, tabs and selects. Before, those apps only received colours, so their controls looked half-finished.
- **Check boxes and radio buttons are visible everywhere.** Unchecked boxes have a clear edge; checked ones fill with Sage and show a dark tick.
- **Input fields read as fields.** Darker than the card behind them, with a visible edge, a Sage outline when focused, and dim placeholder text.
- **Buttons keep one shape language.** 6px corners on buttons, 8px on fields, Sage for the main action, coral for destructive ones — the same shapes the rest of the theme already used.
- **Dark mode is now set system-wide** when the theme is applied, so libadwaita apps stop rendering light windows under a dark desktop. Uninstalling sets it back.
- **The libadwaita helper file is colours only.** It no longer forces the theme's widget styling onto apps that ship their own.

## Bug fixes

- Shelly and other GTK4 tools no longer show invisible check boxes or text-only buttons.
- The blue focus ring and blue progress bars that appeared in some GTK4 dialogs are gone.
- Selected rows in GTK4 lists are a soft accent tint with a visible edge instead of a bright block.
- Disabled buttons, entries and check boxes are now clearly distinguishable from active ones.
- The opt-in libadwaita CSS file no longer overwrites the whole widget stylesheet.

## Notes

- Verified live on GNOME Shell 51.1 with Shelly 3.1.10 and a headless GTK4 widget probe; libadwaita checked with a probe (preferences page, entry, switch, action buttons).
- Icons and cursors continue to live in [mt-verdant-icons](https://github.com/Mayanktaker/mt-verdant-icons).
