# MT Verdant Nocturne v0.2.0

## What's new
- **Complete Application Icon Suite:** Over 100 handcrafted vector icons for popular desktop apps, developer IDEs, AI coding tools, creative suites, web browsers, and gaming launchers.
- **Modern Floating Island Top Bar:** Beautiful 16px curved floating panel that sits gracefully with glowing margins above your desktop wallpaper.
- **Interactive Setup Wizard:** A simple, guided installer that lets you choose your top bar style, window button style, accent flavor, and blur preferences in seconds.
- **Enhanced Window Controls:** Crisp, high-contrast close, minimize, and maximize buttons tailored for both classic and modern application windows.
- **Seamless Quick Settings:** Unified status toggle buttons for Network, Power Profile, and Bluetooth with smooth transitions and ample room for labels.
- **Universal Extras:** Matching theme presets for popular terminal emulators (Kitty, Ghostty, Alacritty, Foot), text editors, Fastfetch, GRUB bootloader, and Plymouth startup animations.
- **Online Showcase Site:** A new responsive web showcase exploring all wallpapers, color accents, and icon packs.

## Bug fixes
- Fixed invisible window close, minimize, and maximize buttons in modern application titlebars.
- Resolved disconnected, split toggle buttons and truncated text in the Quick Settings menu.
- Eliminated double-vision overlapping bars in the top status panel.
- Corrected status icon spacing in the top bar to prevent crowded indicators.
