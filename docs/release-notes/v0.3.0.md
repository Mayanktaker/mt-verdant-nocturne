# MT Verdant Nocturne 0.3.0

© Mayanktaker Computers & Web Development | https://mayanktaker.com

The icon and cursor packs have moved to their own repository, and the theme installer is now
theme-only.

## What's new

- **Icons and cursors are a separate download:** `MT-Verdant-Icons` and `MT-Verdant-Cursors` now
  live at [Mayanktaker/mt-verdant-icons](https://github.com/Mayanktaker/mt-verdant-icons), with
  their own versions, releases and installer. You can update the artwork without reinstalling
  the theme, or use it on a desktop that does not run the theme at all.
- **Lighter theme installer:** the setup wizard no longer asks about icons, and the theme archive
  contains only the shell, GTK, wallpapers and app presets.

## Changing from 0.2.0

The `--icons` and `--no-icons` flags were removed. Any saved command that uses them should drop the
flag and install the pack separately:

```sh
git clone https://github.com/Mayanktaker/mt-verdant-icons.git
cd mt-verdant-icons && ./install.sh
```

Existing icons in `~/.icons` are left untouched by the theme installer.

## Notes

- The standalone icon archive previously attached to the 0.2.0 release has been retired in favour
  of the new repository.
- Theme installs continue to use `~/.themes` only, with no root permissions required.
