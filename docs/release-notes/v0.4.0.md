# MT Verdant Nocturne 0.4.0

© Mayanktaker Computers & Web Development | https://mayanktaker.com

This release makes the theme behave the way it looks: one accent everywhere, wallpapers that ship as a real suite, and an installer that works from the downloaded archive.

## What's new

- **Your accent actually applies everywhere.** Choosing Emerald, Moss or Pine now recolours the top bar, quick settings, GTK3 apps and GTK4 apps together — not just some of them.
- **A proper wallpaper suite.** Eight procedural 4K wallpapers: four night pieces and four matching dawn pieces, generated from one art system. GNOME shows them as adaptive day/night pairs, and a 24-hour timed cycle is included.
- **Much smaller download.** The theme archive is about 3 MB (down from 86 MB) and the full wallpaper suite now weighs ~1.5 MB instead of 67 MB.
- **Clearer surface options.** `--oled` gives true black surfaces, `--rimless` removes window borders, and `--panel` keeps the four top-bar styles. Unknown values now stop with a clear message instead of quietly using a default.
- **Wallpaper options that match the docs.** `--wallpaper light-1..4`, `--wallpaper dynamic` and `--wallpaper timed` now do what they say.
- **Uninstall that leaves no mess.** `./install.sh --uninstall` removes the theme, restores your previous GTK4 CSS if you had enabled the override, and keeps a parked copy instead of deleting anything.
- **A real theme thumbnail** in the appearance picker, plus the display name “MT Verdant Nocturne”.

## Bug fixes

- The released archive now installs itself. The previous release could not.
- Destructive buttons are readable again (dark label on coral in both GTK3 and GTK4).
- Selected rows in lists are a soft accent tint with a visible edge instead of a full bright block.
- Terminal blue and editor comments are legible on the dark background.
- The dash running indicator uses the accent colour again.
- The floating panel hint and the macOS window buttons now match what you select; macOS buttons also move to the left.
- Adwaita icons and cursors are no longer forced when you apply the theme, so your icon pack stays selected.
- The GTK4/libadwaita override is now opt-in and reversible.
- The Arch/CachyOS dependency hint points at the package that actually exists.

## Notes

- GNOME Shell 51.1 is verified live on Wayland (theme loads without CSS parse errors, floating panel renders, Settings matches). GNOME 50.x is built from vendored 50 CSS; a live 50 session test is still pending. Quick settings, calendar, OSD and overview still need a manual pass.
- Blur is provided by the Blur My Shell extension when available; without it, panels are translucent, not blurred.
- Icons and cursors continue to live in [mt-verdant-icons](https://github.com/Mayanktaker/mt-verdant-icons).
