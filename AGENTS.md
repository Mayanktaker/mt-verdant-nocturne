# AGENTS.md — MT Verdant Nocturne

© Mayanktaker Computers & Web Development | https://mayanktaker.com

GNOME dark theme suite: Shell + GTK3 + GTK4 (best-effort) + Flatpak GTK3 extension.
Display name **MT Verdant Nocturne**, technical/theme-dir name `MT-Verdant-Nocturne`.
The companion icon and cursor packs live in **`Mayanktaker/mt-verdant-icons`** and are not built here.

## Stack & toolchain (verify before assuming; update when versions change)
- Targets: GNOME Shell 50.x and 51.x (host dev machine: GNOME Shell 51.1, Wayland).
- Build: `sassc` (libsass 3.6.6), Python 3 + `numpy` 2.5.4 + `Pillow` 13.0.0.
- Repo: git 2.56, `gh` 2.102.1 authenticated as `Mayanktaker`.
- **Installation policy:** ALWAYS install user themes into the user's `~/.themes` (e.g. `/home/<user>/.themes`) ONLY — never `~/.local/share/themes`, `~/.local/share/icons`, or system dirs. `tools/install.sh` implements and must keep this. Shell activation needs the **User Themes** extension (`user-theme@gnome-shell-extensions.gcampax.github.com`). Icon/cursor packs are installed by the companion repo's installer into `~/.icons` ONLY.
- **Installer behavior:** `tools/install.sh` detects distro (`/etc/os-release`) + GNOME Shell major (gate ≥50 with a matching colormap), checks missing packages/modules per distro (python3, gi, sassc, numpy, Pillow, User Themes extension) — only for parts it will actually build — prints the exact distro install command, and uses **sudo only for system package installs** via `--install-deps`; the theme install itself never needs root. Old installs under `~/.local/share/themes` are moved to `deleted_files_folders/`, never deleted.

## Single source of truth
- `palette/tokens.json` — every color in CSS/wallpaper/builds comes from here. No new magic values; add tokens instead.
- Shell theme is derived from upstream GNOME Shell CSS per major version, recolored via `src/shell/` maps (never hand-edit generated CSS).
- GTK4 base is GTK's own Adwaita dark sheet: identity colours come from `src/gtk-4.0/recolor.json`, structural styling from `src/gtk-4.0/overrides.css`. No hand-edited copy of the base is committed.

## Commands
- Contrast gate: `python3 tools/dev/check_contrast.py` (must pass before commits).
- Wallpaper suite: `python3 tools/wallpaper/generate.py --which 1..4|light-1..4|all` and `--verify` → 8 procedural 4K JPEGs in `wallpaper/dist/` + `wallpaper/dist/light/`, previews in `wallpaper/preview/`. XML registration is generated by `tools/wallpaper/generate_dynamic.py`.
- Shell theme build: `python3 tools/shell/build.py [--major N | --all] [--accent sage|emerald|moss|pine] [--out-dir DIR]` (vendored `src/shell/upstream-<major>/` preferred; host gresource is a fallback).
- GTK build: `python3 tools/gtk/build.py [--accent <flavor>] [--out DIR]` → `build/theme/gtk-3.0/`
- GTK4 build: `python3 tools/gtk4/build.py [--accent <flavor>] [--out-dir DIR]` → `gtk.css`, `gtk-dark.css`, `user.css`. A GTK4 theme replaces Adwaita, so the build inlines GTK's own dark base, recolours it via `src/gtk-4.0/recolor.json`, and appends `src/gtk-4.0/overrides.css`. `user.css` is the libadwaita-only colour contract (never the base).
- Token renderer: `python3 tools/theme/render.py --accent <flavor> --dir src/tweaks --out-dir DIR` (tweaks are templates; hex literals are forbidden).
- Gates: `check_contrast.py`, `check_colors.py`, `check_selectors.py`, `check_version.py`; sandbox install `tools/dev/smoke-install.sh .`; release `tools/release.sh 0.5.2`.
- Install: `./install.sh` (interactive CLI wizard) or `tools/install.sh [--panel round-island|pill|bottom-round|flat] [--controls standard|macos] [--accent sage|emerald|moss|pine] [--size standard|compact] [--blur|--no-blur] [--oled] [--rimless] [--wallpaper [1-4|light-1..4|dynamic|timed|all|none]] [--gtk4-libadwaita] [--install-deps] [--uninstall]` → installs theme into `~/.themes/MT-Verdant-Nocturne` (user-only; copies 4K wallpapers into `${THEME_DIR}/wallpapers/` and extras into `${THEME_DIR}/extras/`). Icon/cursor flags were removed in 0.3.0; use the companion repo instead.
- App extras install: `tools/extras/install-all.sh` (scans & installs for all detected apps) or individual scripts under `extras/`.

## Layout
- `palette/` tokens (v0.5.2: colors, accents, geometry, art) · `tools/theme/` token renderer · `src/` per-layer sources (shell, gtk, gtk4, tweaks) · `extras/` (terminals, fish, text-editors, kde, grub, sddm, gdm, plymouth, fastfetch, firefox, vscode) · `tools/` generators (shell, gtk, gtk4, theme, wallpaper) + installer
